# Delivery Summary — extract jev process; jev-cli first model

plan: `extract-jev-process-jev-cli-first-model` · run: `partial` · date: `2026-09-30`

## Intent

This run executed waves 1-10 of the plan: t1-t33, the whole factory (the absorbed nvsh scorer pipeline as 22 `jev run` stages over a declarative domain module, the jev CLI verbs including `jev ask`, the release gate core) plus the operator-approved jev-tool domain content. The jev-tool model build itself (t34-t38) needs the GPU, the teacher lobes and operator gates at each step and was deliberately left for a follow-up results PR, so the run is partial by design.

> jev-factory ships nvsh's Tool-Jev fine-tune process (issue #4, under umbrella #1) as a domain-generic staged pipeline, and the first new model it builds is a jev scorer that operates the jev CLI itself

After: jev-factory owns the full jev-like build pipeline as `jev run <stage>` stages over a declarative domain module, with a state manifest per stage, machine-readable pre-registration and decision records, and every honesty check in code; its first product is a jev-tool scorer on Qwen3.5-0.8B that picks the right jev CLI verb, calibrated and gated, shipped privately as a GGUF bundle
